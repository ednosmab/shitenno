## Bugs Encontrados e Corrigidos

### 1. `reminders` — ícone `undefined` para categorias desconhecidas (HIGH)

**Ficheiro:** `src/commands/reminders.ts:91,139`

**Problema:** `CATEGORY_ICONS[r.category]` retornava `undefined` para categorias não-mapeadas (ex: `"mcp"`). JavaScript interpolava literal `"undefined"` no output.

**Antes:**
```
1. 🔴 Path .shitenno: MCP local-filesystem... undefined mcp
```

**Depois:**
```
1. 🔴 Path .shitenno: MCP local-filesystem... 🏷️ mcp
```

**Fix:** `CATEGORY_ICONS[r.category] ?? "🏷️"` como fallback em ambos os sites (list e add).

---

### 2. `status` — `Active: [object Object]` (MEDIUM)

**Ficheiro:** `src/commands/status/async-displays.ts:116`

**Problema:** `activeCaps.join(", ")` em array de `CapabilityEntity[]` chamava `.toString()` implícito em cada objeto, resultando em `[object Object]`.

**Antes:**
```
⚙ Capability Engine:
  Overall: 46% | Installed: 9 | Dormant: 0
  Active: [object Object]
```

**Depois:**
```
⚙ Capability Engine:
  Overall: 46% | Installed: 9 | Dormant: 0
  Active: Knowledge
```

**Fix:** `activeCaps.map((c) => c.name).join(", ")`

---

### 3. Capability report — mesmo bug de `.join()` (MEDIUM)

**Ficheiro:** `src/capability-engine/report.ts:14`

**Problema:** `caps.join(", ")` em `CapabilityEntity[]` produzia `[object Object]` no relatório de texto.

**Fix:** `caps.map((c) => c.name).join(", ")`

---

### 4. `status` — challenges com mensagem vazia (LOW)

**Ficheiro:** `src/commands/status/async-displays.ts:92-98`

**Problema:** Challenges com `message: ""` apareciam como só ícone 🔵 sem texto.

**Depois:**
```
🎯 Pending Challenges:
  🔵 
  🔵 
  🔵 
```

**Fix:** Filtrar challenges com mensagem vazia antes de renderizar.
